# ADR 0002：采用共享数据库与 PostgreSQL RLS 的多租户隔离

- 状态：已接受
- 日期：2026-08-13

## 背景

项目需要展示 B2B SaaS 租户隔离，同时保持本地开发和演示环境的资源成本可控。

## 决策

- 服务使用同一 PostgreSQL 实例，但每个服务拥有独立 Schema、账号和 Flyway 迁移。
- 业务表使用 `tenant_id`。
- 应用层通过 Hibernate Filter 或 MyBatis 拦截器注入租户条件。
- PostgreSQL RLS 作为最终防线；业务事务设置当前租户。

## 后果

- 业务服务不得使用迁移账号或可绕过 RLS 的高权限账号。
- API、消息和文件访问均需验证租户归属。
- 需要编写 RLS 与跨租户越权测试，避免只依赖代码约定。
